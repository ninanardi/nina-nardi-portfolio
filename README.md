# Nina Nardi — Portfolio

Personal portfolio built with React, Vite, Tailwind CSS, and Framer Motion.

## Stack

- **React** — component structure
- **Vite** — build tool
- **Tailwind CSS v3** — styling with dark mode support
- **Framer Motion** — animations

## Running locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

All content (text, projects, experience) lives in `src/translations.js` and supports Portuguese and English.
